[![XGo](https://img.shields.io/badge/project-XGo-blue.svg)](https://github.com/goplus/xgo)

LLGo bindings for OpenSSL, enabling XGo/Go programs to use TLS/SSL, cryptographic primitives (hashing, symmetric and public-key encryption, signatures), X.509 certificates and random number generation via the OpenSSL C API.
